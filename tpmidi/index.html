TPMidi

MIDI control surface with four rotary encoders, three 75mm faders, and an OLED display. Map each control to CC parameters, Program Changes, or DAW transport functions. See what you're controlling on the live OLED readout. Works with every major DAW.

Why TPMidi

OLED Parameter Display

See parameter names and values in real-time. Know exactly which CC or control you're adjusting.

Four Encoders + Three Faders

Seven independent MIDI controls with full mapping. Rotate encoders for continuous values, use faders for mixer-style control.

Full MIDI Mapping

Assign CC (0–127), Program Change, and transport controls (play, stop, undo, record) to any hardware control.

DAW Compatibility

Works with Ableton, Logic, Reaper, Studio One, Bitwig, FL Studio, and any MIDI-capable software.

Compact Studio Fit

Designed to sit comfortably on any desk next to keyboard or mixer. Quick access to your most-used parameters.

USB Plug & Play

Class-compliant MIDI over USB. No drivers needed on macOS, Windows, or Linux.

Specifications

Encoders 4 rotary encoders with tactile detents
Faders 3 × 75mm linear assignable faders
Display OLED 128×64 character display
Resolution 14-bit MIDI (CC and Program Change)
Update Rate 7ms display refresh, < 5ms control to MIDI
Mapping Options CC, Program Change, Transport (Play/Stop/Undo/Record)
Connection USB-C, class compliant MIDI
Compatibility macOS 10.5+, Windows 7+, Linux
Dimensions 320mm W × 140mm D × 70mm H
Weight 680g
